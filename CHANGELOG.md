# Changelog

All notable changes to Liquid Glass are listed here. Versions follow semantic versioning (MAJOR.MINOR.PATCH).

## 1.2.0

- Profile with a username, display name and icon image. Edit them in Settings; the icon appears in the header.
- Profile data is stored only on this computer.

## 1.1.0

- Settings window (gear icon or Ctrl+,) with a Theme option: Liquid Glass (default) or Plain dark.
- Jamendo client ID and music folder can be changed from Settings.

## 1.0.0

- Monochrome liquid-glass interface with a spectrum visualizer, mini mode and 10-band equalizer.
- Local library with forgiving search (typos, partial words, any word order).
- Jamendo search, streaming and saving tracks to your library.
- MPRIS2 support for media keys and desktop controls.
- Update check at startup with a one-click update button, plus the `liquid-glass-update` command.
- `liquid-glass --version` prints the installed version.
